# Stage Map: SDLC Agent Roles, Artifacts, and Verification Gates

| # | Stage Name | Assigned Agent | Primary Responsibility | Input Context | Produced Artifact | Check Before Moving On | Failure / Backtrack Target | Model & Privilege Tier |
|---|---|---|---|---|---|---|---|---|
| **1** | **Requirements** | Requirements Agent | Formalize issue into testable acceptance criteria | Sanitized Issue Title & Body | `spec.md` | Deterministic verification: All acceptance criteria have concrete Given-When-Then test conditions | Halt with explanation in `spec.md` | Gemini Flash / Read-Only |
| **2** | **Design** | Design Agent | Architect code modifications and file impact | `spec.md` + `ARCHITECTURE.md` + Repo tree | `design.md` | Static verification: Target files and functions exist or are formally declared for creation | Halt with explanation in `design.md` | Gemini Flash / Read-Only |
| **3** | **Implementation** | Implementation Agent | Apply code edits on dedicated issue branch | `design.md` + codebase + test error traces (if retry) | `diff.patch` | Build verification: Modified files parse cleanly (`ast.parse`) with zero syntax errors | Halt with diagnostic output | Gemini Flash / Read-Write (No push) |
| **4** | **Testing** | Testing Agent | Author acceptance tests & execute full test suite | `spec.md` + `diff.patch` | `test_report.md` | 100% of newly authored tests pass AND 100% of baseline tests pass (0 regressions) | Retry $\to$ Stage 3 (max 3 retries); Escalate $\to$ Stage 2 if structural | Gemini Flash / Read-Write + Execute (`pytest`) |
| **5** | **Release** | Release Agent | Commit branch, push to origin, and open PR | `diff.patch` + `spec.md` + `test_report.md` | `pr.md` + PR URL | PR is open and active via GitHub API; workflow CI checks status is green | Halt run, log API failure | GitHub Actions Token (`pull-requests: write`, `contents: write`) |
| **6** | **Review** | Independent Reviewer Agent | Adversarial code review with fresh context | Clean PR Diff + original issue text only (zero agent scratchpads) | `review.md` | Reviewer issues `APPROVE` or review budget (max 2 rounds) is exhausted | If `REQUEST_CHANGES`:<br/>• Code bug $\to$ Stage 3<br/>• Design flaw $\to$ Stage 2 | Gemini Pro (or Flash with adversarial prompt) / Read + Execute (Strictly No Push) |
| **-** | **Merge Gate** | **Human Maintainer** | Final merge / close decision | Pull Request, artifacts, and reviewer findings | Merged branch | Human judgment only | Close PR or request manual revision | Human Maintainer |
